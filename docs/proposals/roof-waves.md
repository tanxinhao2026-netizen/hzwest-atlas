# 提案 · 屋面云纹（hark-cs，任务书 docs/tasks/roof-waves.md）

## 一句话
把屋面从「一个光滑鼓包」改成「四朵云 + 外圈软波纹」：四块金属屋面各自鼓起 3.5 m，外圈叠 0.5 m 的同心波纹，十字天窗两侧归零留出「云的缝」。**只叠在金属屋面（覆面 `Hc`）上，钢结构 `Ht`、提升高度 D、工期全不变。**

## 依据（公开资料）
- 设计说法：「如果将屋顶的四角看作云，大天窗则象征着云雾的缝隙」（杭州日报 2022-09-08）。
- 屋面长边约 334 m、短边约 249 m，最高点标高 60.75 m（中国日报 2021-08-31）；天窗 1.25 万 m²，拱形（杭州日报 2022-09-16）。
- 「云谷」是两车场之间 28 m 宽的竖向通廊，不是屋面凹槽；所以天窗保持隆起，云纹做在四块屋面上。

## 公式（叠在 `HZ.rho` 上，加进 `Hc`）
```js
// u, v：到中心的相对距离（0 中心，1 外缘）；r = rho(x, z)
const WV = { A1: 3.5, A2: 0.5, lob: 0.32, per: 0.18, gap: 14 };
const Wv = (x, z) => {
  const u = Math.abs(x) / P.roofA, v = Math.abs(z) / P.roofB, r = rho(x, z);
  const g = sm(P.skyW, P.skyW + WV.gap, Math.min(Math.abs(x), Math.abs(z)));        // 天窗两侧 14 m 内渐变到 0：云的缝
  const lobe = WV.A1 * Math.exp(-(((u - 0.5) / WV.lob) ** 2 + ((v - 0.5) / WV.lob) ** 2)); // 每块屋面中心一朵云
  const rip = WV.A2 * Math.sin(2 * Math.PI * r / WV.per) * sm(0.55, 0.7, r) * (1 - sm(0.84, 0.96, r)); // 外圈波纹，边缘 15% 不动
  return g * (lobe + rip);
};
const Hc = (x, z) => Wv(x, z) + Ht(x, z) + 0.5 - 0.8 * sm(0.85, 1.0, rho(x, z)) + /* 原天窗项不变 */ ...;
```
- 幅值：云 3.5 m、波纹 0.5 m，波纹一圈约 20–30 m。屋面最高点仍是天窗中心 57.3 m（云最高约 51 m，比天窗低，天窗仍是主角）。
- 低于 1 m 的单独起伏在 300 m 外看不出来；四朵云要 ≥3 m 才在远景读得出（A 版 2.5 m 偏弱）。
- 满铺 1 m 波纹（B 版）像等高线梯田，太花，不推荐。
