# 提案 · 构件身份卡与跨图关系（hark-fangyi，2026-11-08）

委托人要的核心：点到任何一个具体构件，就能看到**它在哪、长什么样、和谁有关系、哪天建成、建成后实际什么样**。联动 v2 解决了「点 → 飞镜头」，但「看到什么」现在各图各画，S-201 二稿的身份卡是一份试做。建议把它变成全图册通用的一层。

## 一、通用身份卡（宿主画，插件只给数据）
插件新增可选 `info(id, t)` → `{ title, lines: [[键, 值], …], rel: [{ sheet, id, why }], rec: ['R-0009', …] }`。
- 键固定五个：**位置 / 关系 / 工期 / 实物 / 建成**，各图同一格式、同一位置。
- 宿主统一画在图纸与 3D 之间（或 3D 黄框旁），手机竖屏也能放下；插件不再各自画卡片。
- S-201 二稿已实现 `info(id, t)`，可直接当样板。

## 二、跨图关系 `rel`（点一下跳到另一张图的同一个东西）
- S-201 股道 → S-401 正上方屋面分区（ZN/ZM/ZS）、S-101 正下方地下层；S-301 提升器 → S-201 下面压着的承轨层跨。
- 宿主把 `rel` 渲染成可点的小链接：`#sheet=S-401&focus=ZM`。关系由几何算（3D 盒在平面上重叠），不手写。

## 三、实物层挂到构件上
- `HZR.RECORDS[].anchor` 目前只认 `J#`、分区和 `HZ.K` 键；建议再认 `<图号>:<part id>`（如 `S-201:G-N09`），由 check_real 调该插件 `parts()` 解析。
- 宿主在 3D 里为有记录的构件打一个小图钉；身份卡「实物」行列出它的记录，点开原链接（只存链接，不存图）。
