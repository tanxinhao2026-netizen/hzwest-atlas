# 任务书 · 图纸二稿：联动接口 v2（所有插件图纸必读）

**委托人结论（2026-11-08 11:56）**：S-101 / S-201 / S-401 初稿还是草图；数据没有像 S-301 那样和 3D、工期建立联系。二稿必须做到「图纸 ↔ 3D ↔ 时间」三向联动。

## 一、数据必须来自同一份模型（硬要求）
- 图上的每个构件、尺寸、数量从 `HZ`（构件 `HZ.segs`/`HZ.acts`/`HZ.times`、常量 `HZ.K`/`HZ.P` 等）读，不写死坐标和数字。
- 判定办法：改 `HZ.K` 里一个尺寸或工期，图要跟着变。`check_<图号>.js` 里加一条这样的测试。
- 公开事实（日期、长度）若模型里没有，写进 `CLAIMS.md`「接口请求」请 hark-cr 加进 HZ，不要在插件里自建一份。

## 二、插件新增字段（可选但二稿必须实现 `parts`）
```js
{
  ...原有 id/name/window/big/draw/cam/segs,
  parts(t, ctx) {           // 当前时刻图上可点的构件
    return [{ id: 'W-03',   // 图内唯一，进 URL：#sheet=S-101&focus=W-03
              label: '地连墙 W-03',
              hit: [x, y, w, h],          // draw() 坐标系里的点击框（宿主负责缩放平移换算）
              box: [x0, y0, z0, x1, y1, z1] // 对应 3D 世界盒（米），镜头据此飞过去、画黄框
            }];
  },
}
```
- `draw(g, w, h, t, ctx)` 的 `ctx` 新增：`ctx.focus`（当前选中的 part id 或 null，选中项请加粗/描黄）、`ctx.zoom`（只读，当前缩放倍数，可用来决定细节层级）。
- 宿主（hzview，hark-cr 负责）统一提供，插件不用自己写：图纸滚轮/双指缩放 1–8 倍、拖拽平移、双击复位；点 part → 1 秒镜头飞到 `box` 并画黄框；在 3D 里点到落在某 `box` 内的构件 → 图纸居中放大到该 part；`#focus=` 进出 URL；时间拖动时镜头跟随选中 part。

## 三、画面要求（沿用 BRIEF）
墨线语言、一屏、一个大数字、少数字、文字不重叠不出界；1258×540 小屏也要能读。

## 四、交付与验收
- 只改自己的 `web/sheets/<图号>.js`、`tools/hz/check_<图号>.js`。
- `check_<图号>.js` 要检查：`parts()` 在时间窗内每个采样时刻都返回 ≥1 项、id 唯一、hit 在画布内、box 有限且非零体积；以及第一节的「改 HZ 图跟着变」。
- `node tools/hz/check_all.js` 输出 `OK check_all 4/4`。
- 推送到收件仓库（或 PR）后，只改上述两个文件的交付会自动合并（见 AGENTS.md 第 5 节）。

宿主接口上线前可以先写 `parts`；宿主上线后 CHANGELOG 会有一行「联动接口 v2 上线」。
