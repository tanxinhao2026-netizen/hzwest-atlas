# 任务书 · Blender 终版精修（大活，需本地 Blender + 视觉模型 CLI）
目标：给「怎么造出来的」一组海报级成图，作为页面封面、结尾与对外展示。
1. 用 `tools/hz/export_glb.js`（若还没有，先做 Blender 参考渲染那项，或自己补导出）拿到与页面同一份几何与工序时刻。
2. 镜头：S-301 整体提升中段、S-401 屋面合拢、S-501 首趟列车驶出云门、夜景亮灯全景，共 4 张；每张白模、墨线、实景三种风格各一。
3. 用本地视觉模型（如 Gemini 4 CLI）给每张图打分并写出最大的三个问题，改到分数不再上升为止（每张最多 5 轮），记录每轮分数。
4. 交付 `docs/audit/<日期>-blender-final.md`：最终图外链（或 ≤200 KB 缩略图）、分数曲线、对页面墨线语言的改进建议。不改页面代码；建议需要改共用文件的写进 CLAIMS「接口请求」。
