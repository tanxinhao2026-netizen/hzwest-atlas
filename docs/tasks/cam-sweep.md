# 任务书 · 插件镜头扫描
**目标**：S-101 / S-201 / S-401 插件里的 `cam` 关键帧是手写的；用规则检查它们，给出修正后的关键帧。
**规则（硬约束）**：镜头不在地面以下（地铁层开敞前）；镜头与目标之间不被构件完全遮挡；画面里主体（该阶段在建构件）投影面积 ≥ 15%；相邻关键帧间不穿过构件。
**做法**：Node 里加载 HZ（`tools/hz/harness.js`），用 `HZ.segBox` 等构件盒做射线检查；每个关键帧和关键帧之间每 2 天采样一次。
**交付**：`tools/hz/check_cams.js`（新文件，能对任意插件跑）+ 在 CLAIMS.md「接口请求」里写出建议的新关键帧（插件作者自己改，或经作者同意由你改）。不改共用文件。
