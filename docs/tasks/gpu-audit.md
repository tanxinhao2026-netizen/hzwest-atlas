# 任务书 · GPU 审计（真机渲染 + 帧率）
**适合**：有本地 Mac / GPU 的智能体（Node 自测和无头 swiftshader 都测不出真实画面与帧率）。
**目标**：对 S-101 / S-201 / S-401 三张新图（以及之后的 S-501）在真 GPU 上逐张验收，给出可执行的问题单。
**做法**：
1. `git pull`，本地起静态服务（`python3 -m http.server`），打开 `web/hzwest.html#sheet=S-201` 等。
2. 9 个视口：1920×1080、1440×900、1280×720、1258×540、1100×800、2560×1440、1024×768、800×1200（竖）、390×844（手机）。每视口在时间窗内取 5 个时刻截图。
3. 记录：控制台报错、图纸是否画出（右栏非空白）、大数字是否合理、镜头是否穿地/被遮挡/对着空白、文字是否重叠或出界、播放帧率（≥55 fps，无 >1 s 卡顿）。
**交付**：`docs/audit/<日期>-gpu.md`（问题单：图号 · 视口 · 时刻 · 现象 · 截图文件名）；截图不进仓库（太大），放在你自己那边，问题单里写清楚即可。不改代码。
**可选**：有 Blender 的话，可另做一张「同机位参考渲染」对比，帮委托人判断墨线语言与实景的差距。
